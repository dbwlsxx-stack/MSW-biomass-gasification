# MSW–Biomass Gasification Modeling and Optimization

This repository contains the code used for data processing, feedstock clustering, machine-learning modeling, model interpretation, and operating-condition optimization in this study.

## Data

The complete processed dataset used in this study, including the bibliographic source information for each observation, is provided separately as **Supporting Information 2** accompanying the manuscript.

The data provided in Supporting Information 2 can be used as the input dataset for the codes included in this repository.
